\section{YOLO segmentation model}
\label{sec:yolo}

We trained a YOLO26 \cite{jocher2026ultralyticsyolo26unifiedrealtime} semantic segmentation model by using the ultralytics python library. We used the nano variant which has 1.6M parameters.
The model is used in our pipeline to preprocess the images that are recorded by the duckiebot before we pass it into the CNN that controls the duckiebot's wheel velocities.
Concretely we train the model to predict 3 semantic classes: the white lane markings, the dashed yellow lane markings and the red markings.
To train the YOLO model we recorded a dataset of around 5.000 images while driving around Duckietown and then generated high-quality masks with the SAM3 \cite{carion2026sam} model from Meta.
These masks serve as the ground-truth labels when training the YOLO model.
During training we used the pretrained yolo26n-sem checkpoint from the ultralytics library with default settings, only adjusting the input image size, and trained for 5 epochs.
The resulting YOLO model produces very good segmentations of the lane markings in Duckietown.
See figure \ref{fig:sem_example} for an example segmentation mask.
The predicted segmentations mask $s_t$ is then used as the input for the CNN models described in section \ref{sec:cil}.

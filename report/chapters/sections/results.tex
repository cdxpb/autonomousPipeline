\section{Results}
\label{sec:results}

The exact task definitions can be observed in fig. \ref{fig:tasks}. 
We have tasks that test each intent in isolation and also do a long run to test long term stability. 
For each task, we test our model five times in each direction of travel and report how often the model succeeds. 
The results can be viewed in table \ref{tab:results}. 
We observe that in general, both architectures are able to control our bot relyable, but have some specific weaknesses or biases. 
For example the MH architecture sometimes fails on the isolated intent tasks, especially on left turns at intersections, 
but is more robust at the long-term experiment, because it is able to recover from slight errors. 
FiLM on the other hand is basically perfect on the isolated intent tasks (not as accurate on straight intent), but surprisingly is not as robust on the long term task. 
Concerning \textbf{a)} we find, that FiLM is in general a bit more accurate. 
To improve the weaknesses of our models, we retrained our models with an adjusted sampling strategy. 
For MH we used $[30, 20, 30, 20]$ and for FiLM $[30, 30, 20, 20]$. 
So \textbf{b)}, we observe, that this indeed helped to fix weaknesses. 
Especially the MH model improved the performance on the left turns severly but slightly loses performance on lane following. 
Another unintentional and interesting observation is, that both models are robust under wrong intent setting. 
For example given the right intent, the MH model can also do lane following as long it has no left corners, enabling it to run in a right turn loop.

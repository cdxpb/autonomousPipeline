\subsection{Multiple Head Architecture (MH)}
\label{subsec:mh}

As vizualized in figure \ref{fig:multibleHeads}, we first pass the current frame $f_t$ to a CNN backbone to produce visual features. 
Based on the current intent, we then pass these features to a specialized head \cite{CodevillaMH}, which then predicts the target wheel velocities $MH_{\theta}(s_t, c_t) \approx v_t$.

\subsection{Multiple Head Architecture (MH)}
\label{subsec:mh}

This architecture is based on \cite{CodevillaMH}.
As vizualized in figure \ref{fig:multipleHeads}, we first pass the current frame $f_t$ to a CNN backbone to produce visual features. 
Based on the current intent, we then pass these features to a specialized head which then predicts the wheel velocities.
